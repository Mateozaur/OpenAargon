Level Notes


This level is actually the result of the discovery of a bug we found while developing Aargon Deluxe. We had always thought that we could make the pieces any way we wanted and that there would be no problems. Boy, were we wrong with the threeway! We discovered, much to our embarrasment, that the threeway can be used in such a way as to create a circular path of light. That is, if you position the threeway in a certain way combined with some mirrors, you can make the laser light go around in a circle and never terminate. Gabor Vekony pointed this out, and was able to make the game crash by creating such a configuration. We eventually solved the dilema by only allowing 1 loop per beam. We then created this level as an example of how an infinite beam loop can be used in combination with a color converter to create white light.
