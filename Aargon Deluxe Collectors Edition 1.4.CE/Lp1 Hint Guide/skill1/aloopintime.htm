Level Notes


It turns out that this level has an interesting history. You may not know it, but this level was accidentally shipped with the old version of Aargon 1! You see, Steve Verreault was working on this level right about the time Aargon 1 was released. The level was accidentally added to the installation program and wound up being installed into the levels directory as a file called "DELETED". When I discovered the level (this is Alan Carre writing), I thought it was an interesting looking idea the way the level played backwards and forwards in the same way so I decided to try to finish it and include it in a level pack. Thus the name "A Loop In Time" not only refers to the fact that the level is a series of loops, but also to the fact that it brings us back to the original Aargon in an unexpected way.
