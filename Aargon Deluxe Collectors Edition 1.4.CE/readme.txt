Aargon Deluxe Readme
====================

For specific information also see (File_id.diz, ombudsman.txt, license.txt)

System Requirements
===================

Supported Operating Systems: Win95,Win98,WinME,
                             WinNT 4.x,Windows2000 
System Requirements:         Pentium class, 4mb video card, 
                             Direct X 3.0 or later, 
							 Direct X 6.1 for music
Install Support: Install and Uninstall


Description
===========

*THE* Laser, Light,  and Color Puzzle Game! You must try 
to decipher the subtle hints left in the laboratory 
to solve over 120 stunning Laser Puzzles. Change colors, 
reflect light, fence in robot mines, and feed slime creatures 
to find the solution.


Support
=======

Known bugs:
  1) Under Windows NT v4.0, we have seen that the startup dialog box may display
     the Aargon Deluxe logo incorrectly. This is not a serious problem and should
     not interfere with the normal operation of the program.

See the troubleshooting section of our manual for more information regarding bugs
and possible fixes. You may also contact support@twilightgames.com
