Level Notes


This level started out with a solution far different from what it became in the end. It was discovered that the same level could be solved in a rather straight forward way if we started out with a red beam. This was possible because of the use of the back-complementing technique. Furthermore, the location of the blue coin (initially closer to the left) was not as confined as it was with the original, intended solution. So we decided to change the level by moving the blue coin far away, and thus forcing the back-complement style solution. This also allows for the level name to be a hint where the key is to "lay off" blue (ie. to discard it initially) in order to actually hit blue!
