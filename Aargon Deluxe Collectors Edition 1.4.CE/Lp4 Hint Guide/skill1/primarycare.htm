Level Notes


Although this level is quite easy, it demonstrates an important feature of the color converter when used with a symmetric color-splitting piece. If a loop is formed, and the beams within the loop are converted so as to be allowed "back in" to the color-splitting piece, then they can be recombined via back-reflection!
