Level Notes


This is another one of my favourites from Olivio. Essentially we have three seperate levels in the same level, however we don't know which pieces go with wich sublevel! Also, each sublevel contains 3 coins. With all these 3's showing up and given that each sublevel has a pretty solution, and contains 3 coins we came up with the perfect name for it "Three Little Gems" referring both to the coins and sublevels. Unfortunately we had to abandon that name for the medical theme :'(
