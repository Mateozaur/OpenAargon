Advanced Controls



While Playing

Arrow keys can be used to move yellow selection around

Enter Can be used to pick up or drop a piece
Ctrl+Q can be used to quit the game
Ctrl+Z can be used to undo last move
Ctrl+Y or Ctrl+A can be used to redo a move
Ctrl+G changes the grid brightness (gamma)
Left click on a selected piece will rotate it counter-clockwise
Right click on a selected piece will rotate it clockwise
Escape key can be used to go back one screen in most cases

While Editing

See: Advanced Keyboard Support

Other Keys

Alt+Enter - Toggle Windowed/Full-Screen mode
Alt+Tab - Minimizes Aargon; Switches to other windows
