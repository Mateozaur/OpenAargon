Troubleshooting

If you're having trouble running Aargon Deluxe or the Aargon Deluxe Demo then we recommend you try the following.

1) Check readme.txt for Aargon Deluxe. This is available from the start menu. It will have the very latest information.

2) Check the 'Known Bugs / Problems' section below to see if your problem is listed.

3) Check the support pages on our web site at http://www.twilightgames.com

4) Contact support@twilightgames.com and ask us for help.

We've done everything we can to make sure that the program is bug free. However, due to the large variety of systems, video cards, Windows versions, and sound cards it's very difficult to test in such a way that we're certain the game will run well on all systems. Below is a list of issues we are aware of and how you might fix them.

CD Player, and DirectX : There is a known incompatibility with DirectX and Windows2000. If you are running the game in 256 color mode and the have Windows CD player in your system tray the game may minimize at startup. There are two solutions to this. You can switch your desktop mode to hicolor or true color mode (recommended) or you can disable cd-player when running Aargon. You may maximize CD player so that it is displayed on the desktop as well as in the system tray. This bug can be seen in most commercial games as well as Microsoft's own game programming examples. To change your display mode you can right click on your windows desktop and select properties. Select the settings tab. Different video card drivers will display a different set of options at this point. There is usually a section called color. You want to select True Color (sometimes referred to as 24 or 32 bit color), or Hicolor (sometimes referred to as High Color or 16 bit). If you are running an older or slower system or your video card is slow you should choose Hicolor first as it will generally run faster.

Aargon Runs Too Slow! : If you have an older slower computer, you can speed Aargon up by turning off the music in the options panel before starting. Turning off sound effects may also help.

Music And Windows NT 4 : DirectMusic is only supported in DirectX versions 6.1 or greater. The highest version of DirectX released by Microsoft for NT 4.was DirectX 3.0.Therefor if your are running the game under NT 4.0 Music will be disabled. There is no fix for this unless you upgrade to Windows2000 which supports newer versions of DirectX. Other than that the game should run fine without Music.

When I try to use the editor I get a message saying that I need HiColor or TrueColor on my desktop but my desktop IS set to use HiColor or TrueColor! If you see this error, chances are that your display driver is out of date. Contact your video card manufacturer to get the latest drivers.

I see a message box that says 'Oops!' : If a severe error occurs while running the game you will see this box with a 1 line description of the error. The guidelines below may help you to remedy the problem:
Error 1: Required file missing -- The program or one of its components is installed incorrectly. Try completely uninstalling the game and then reinstalling it. Note: If you have purchased the full version of the game, you will need to apply the upgrade patch after reinstalling the demo version.
Error 2: Cannot set display mode -- Aargon Deluxe requires a minimum of 800x600 pixels and 16 bit color resolution. If you see this error, either your video card does not have enough memory or the driver is installed incorrectly. Contact your video card manufacturer to get the latest drivers.
Error 3: DirectX Initialization failed -- Aargon Deluxe requires a system add-on called DirectX. This add-on only comes with Windows 95 or greater, WindowsNT 4.0 or greater, and Windows 2000. Contact your software vendor to make sure that you are running an operating system that supports DirectX. Also, make sure that you are not running in safe mode and that your video drivers are properly installed.
Error 4: Unexpected video mode switch -- This error can indicate that another application is interfering with the normal operation of Aargon Deluxe. See the comments above about CD Player for more information.
Error 5: UNHANDLED EXCEPTION -- If you see this error, it is probable that the program or one of its components is installed incorrectly. Try uninstalling the program and then reinstalling it. Note: If you have purchased the full version of the game, you will need to apply the upgrade patch after reinstalling the demo version.
