This is a sample page to show how the HTML pages in the hint guide are used. This page is similar to the actual hint pages, except it contains these extra instuctions in red text.

Please use care when getting the next hint. Too many hints will ruin this game for you, and the temptation to use a hint is strong. That was the main reason the game does not contain built in hints. While we've attempted to make the first few hints obscure, in many cases even the simplest hint, like giving away a single piece location, can also give away the entire solution.

Also note that two new level packs were added when you installed this hint guide.

One of them contains new tutorial levels. These tutorials, unlike the ones that came with the game are skill-building tutorials that discuss strategies you can use to solve levels you're having a tough time with. Try using these strategies and ideas before referring to hints because it's much more satisfying to solve the puzzles yourself.

The other contains the full solutions for every deluxe level. You can use them to compare your answer with ours. Sometimes they might be different. The solutions level pack is designed so that you can look at a single solution without seeing the others, so don't be afraid to go look at one or two. Once it's uncovered though it stays uncovered. So if more than one person is using the same computer to play the game keep in mind that you're uncovering the solution for them as well.

Below you will see four sections. The level title area, word hints, picture hints, and level notes. All the hints are covered so that you won't accidently see a hint before you need it. The level notes aren't hints, but sometimes details in the notes can give away the solution or discuss the solution so they are covered too. Note that if you come back to a page or refresh the page in some way the hints will be covered again. Scroll down for more details on how to use the hint page.

These are the picture hints. Most of the time they are direct hints, such as where a piece should go, or a partial solution to the level, but occasionally they are less obvious, and are only intended to give you a clue about a pattern used in the level. As with the text hints you need to click to reveal them. Click on the words Hint1 through Hint5 to show the different pictures. Note that somethimes the picture hints and the word hints offer the same clue. The picture hints are easy to see whereas the word hints could be misinterpreted. The picture hints start out obscure at hint 1 and become more detailed towards the higher numbers.
